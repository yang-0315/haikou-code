# 产品方向：海南政策更新与执法问答平台

## 定位

问答保留，但不是一堆静态文件上的通用问答，而是**持续维护的海南政策库的前台能力**。
产品的核心价值是：

1. 跟随海南官方渠道持续发现法规、规章和规范性文件的新增、修订、废止及部分失效。
2. 每条效力变化都有官方链接、证据句、核对人、核对时间和历史版本。
3. 更新通过审核后重新进入检索和问答，不把旧索引继续冒充最新政策。
4. 政策问答与执法事项问答使用同一套现行效力和历史版本数据。

一句话：

> 问得准只是入口；库跟得上、效力有官方依据、变化能追溯，才是产品本体。

## 三条业务线

### 1. 海南政策库持续更新

- 监测省人大、省政府、省政府部门及重点主管单位官方网站。
- 区分新增文件、正文变化、附件变化、修订、废止和部分失效。
- 生成更新候选和差异报告，不直接静默覆盖现行政文库。
- 保留来源 URL、抓取时间、页面/附件哈希、正文哈希和版本关系。

### 2. 效力追踪与官方补证

- 自动抽取公布日期、施行日期、废止日期、修改依据和“同时废止”条款。
- 自动识别新增废止、修改决定、重新公布文本和条文级部分失效。
- 证据不足时进入人工复核队列，状态保持“效力存疑”。
- 官方补证必须记录核实人、时间、官方 URL、证据句和说明。
- 审核通过后重新计算日/月/年历史时点和当前效力。

### 3. 政策与执法事项问答

问答保留三类入口：

- **通用政策问答**：某项规定是什么、适用于谁、依据是什么。
- **变化问答**：最近有什么新规、某文件改了什么、从何时生效、影响哪些事项。
- **执法事项问答**：处罚事项、法律依据、条款、实施主体、罚款幅度、现行效力。

所有回答必须：

- 优先引用现行有效的官方文本。
- 明确区分当前效力和历史时点效力。
- 给出法规名称、条号、官方来源和必要的核实提示。
- 检索不到或效力不足时拒答或降为存疑，不生成无条件结论。

## 更新闭环

```text
官方渠道监测
  → 发现新增/正文变化/附件变化/废止/修订
  → 获取官方原文与附件
  → 正文与结构解析、版本差异
  → 生成效力事件和待补证队列
  → 人工核对官方证据
  → 版本化发布、重新计算效力
  → 重建检索/事项/树索引
  → 政策问答、变化问答、执法事项问答
```

任何自动发现都不能直接升级为“现行有效”或“已废止”。自动处理负责发现和整理，
最终发布必须保留证据链。

## 更新账本

建议形成独立、可审计的 `_update_ledger.json`：

```json
{
  "scan_id": "2026-11-23T...",
  "source": "official-url",
  "kind": "new|body_changed|attachment_changed|amended|repealed|partial_repeal",
  "title": "文件标题",
  "official_url": "https://...",
  "source_hash": "sha256",
  "body_hash": "sha256",
  "detected_at": "2026-11-23T...",
  "review_status": "pending|verified|rejected",
  "evidence": "官方证据句",
  "verified_by": "",
  "verified_at": "",
  "published_version": ""
}
```

同一文件的不同版本必须能通过版本谱系关联，不得只按标题覆盖。

4. 可安全执行的一键发布流程：备份、审核校验、重建所有受影响索引。**已完成，
   包含并发锁和失败回滚**。
5. Web 增加“最近更新”和“待核实变化”，问答回答附更新时间与官方来源。
   **更新状态面板已完成；回答级更新时间仍属于下一阶段。**

## 与北大法宝的关系

不与其比“全国法规数据量最大”。本产品聚焦：

- 海南本地政策的更新速度和官方证据链。
- 本单位关注范围内的持续追踪、批量变化报告和内部复核。
- 政策变化对历史问答、执法事项和实施主体影响的自动联动。
- 通用政策问答作为更新库的自然入口，而不是孤立卖点。
